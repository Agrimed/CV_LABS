## Цель работы

Научиться создавать простую систему классификации изображений на основе
свёрточных нейронных сетей, обучить модель на выбранном датасете и
оценить её качество на валидационных и собственных тестовых
изображениях.

## Описание работы

В лабораторной работе реализована система бинарной классификации
изображений домашних животных на два класса:

-   **Cat** --- кошки;
-   **Dog** --- собаки.

В качестве основного датасета используется **Oxford-IIIT Pet**. Для
обучения и валидации применяются изображения из датасета, а для итоговой
проверки подготовлена отдельная тестовая выборка из 50 собственных
изображений: 25 кошек и 25 собак.

В качестве модели используется предварительно обученная
**MobileNetV3-Small**. Для адаптации сети к нашей задаче применяется
Transfer Learning: готовая модель используется для извлечения признаков,
а классификатор настраивается на два целевых класса.

## Теоретическая база

### Свёрточные нейронные сети

Свёрточная нейронная сеть (CNN) --- тип нейронных сетей, предназначенный
для обработки изображений. Свёрточные слои выделяют визуальные признаки:
границы, текстуры, формы и более сложные элементы объектов. На основе
извлечённых признаков классификатор определяет, к какому классу
относится изображение.

### MobileNetV3-Small

**MobileNetV3-Small** --- компактная архитектура свёрточной нейронной
сети, рассчитанная на эффективную работу при ограниченных вычислительных
ресурсах.

В работе используется версия модели с предобученными весами ImageNet.
Последний слой классификатора заменён на слой с двумя выходами --- по
одному для каждого класса.

### Transfer Learning

Transfer Learning (перенос обучения) позволяет использовать знания
модели, полученные при обучении на большом датасете ImageNet, для
решения новой задачи.

В данной работе: - используются предобученные веса MobileNetV3-Small; -
слои извлечения признаков заморожены; - классификатор адаптирован под
классы Cat и Dog; - обучение выполняется для параметров классификатора.

### Функция потерь и метрики

Для обучения используется взвешенная функция потерь **Cross-Entropy
Loss** (`nn.CrossEntropyLoss` с весами классов). Веса помогают учитывать
дисбаланс количества кошек и собак в обучающей выборке.

Для оценки качества используются: - **Accuracy** --- доля правильных
предсказаний; - **Precision** --- доля правильных предсказаний класса
среди всех предсказаний этого класса; - **Recall** --- доля найденных
объектов класса среди всех объектов этого класса; - **F1-score** ---
гармоническое среднее Precision и Recall; - **Confusion Matrix** ---
матрица ошибок, показывающая правильные и ошибочные классификации.

## Установка и запуск

Виртуальное окружение `.venv` находится в корневой папке репозитория
`cv` и используется лабораторными работами совместно.

### 1. Создание виртуального окружения

Если `.venv` ещё не создано, выполни команды из корневой папки
репозитория:

``` powershell
python -m venv .venv
```

Активируй окружение:

``` powershell
.\.venv\Scripts\Activate.ps1
```

Если окружение уже существует, повторно создавать его не нужно.

### 2. Установка библиотек

PyTorch и Torchvision должны быть установлены в совместимых версиях с
поддержкой CUDA. В используемом окружении установлены PyTorch
`2.14.1+cu130` и Torchvision `0.29.1+cu130`.

Остальные зависимости можно установить командой:

``` powershell
python -m pip install numpy matplotlib scikit-learn pillow pillow-avif-plugin tqdm ipykernel jupyter
```

### 3. Запуск ноутбука

1.  Открой репозиторий `cv` в Visual Studio Code.
2.  Открой файл [lab3.ipynb](./lab3.ipynb) внутри папки `lab3`.
3.  Выбери Python-интерпретатор и Jupyter-ядро из корневого виртуального
    окружения `.venv`.
4.  Запусти ячейки последовательно сверху вниз.

При первом запуске датасет Oxford-IIIT Pet загружается в папку `data`,
если его там ещё нет. Собственные тестовые изображения должны находиться
в `test_images/cats` и `test_images/dogs`.

## Подготовка данных

Для обучения и валидации использован датасет Oxford-IIIT Pet, содержащий
3680 изображений кошек и собак.

Датасет разделён на две части:

  Выборка           Количество изображений
  --------------- ------------------------
  Обучающая                           2944
  Валидационная                        736
  **Всего**                       **3680**

В обучающей выборке содержится 950 изображений кошек и 1994 изображения
собак. В валидационной выборке --- 238 изображений кошек и 498
изображений собак. Для компенсации дисбаланса классов при обучении
используются веса классов в функции потерь.

Перед подачей в сеть изображения приводятся к размеру 224 × 224 пикселя,
преобразуются в тензоры и нормализуются с параметрами, используемыми для
предобученных моделей ImageNet.

Для итогового тестирования создана отдельная выборка из 50 изображений,
которых не было в обучающей и валидационной выборках: - 25 изображений
кошек; - 25 изображений собак.

Поддерживаются форматы JPG, JPEG, PNG, WEBP, BMP и AVIF. Для чтения AVIF
используется библиотека `pillow-avif-plugin`.

## Обучение модели

Обучение проводилось в течение 10 эпох. После каждой эпохи оценивалось
качество на валидационной выборке. Лучшая модель сохранялась в файл:

`models/mobilenet_v3_small_best.pth`

Лучший результат был получен на **7-й эпохе**:

  Показатель              Значение
  --------------------- ----------
  Train Loss                0.0200
  Train Accuracy            99.05%
  Validation Loss           0.0191
  Validation Accuracy       99.32%

По результатам обучения не наблюдается выраженного переобучения: на
лучшей эпохе значения точности обучающей и валидационной выборок близки.

## Результаты валидации

На валидационной выборке из 736 изображений получены следующие
результаты:

  Класс                  Precision   Recall     F1-score   Количество
  -------------------- ----------- -------- ------------ ------------
  Cat                       98.74%   99.16%       98.95%          238
  Dog                       99.60%   99.40%       99.50%          498
  **Общая Accuracy**                          **99.32%**      **736**

Матрица ошибок:

  Истинный класс     Предсказан Cat   Предсказан Dog
  ---------------- ---------------- ----------------
  Cat                           236                2
  Dog                             3              495

Таким образом, модель правильно классифицировала 731 изображение из 736.
Ошибочно были классифицированы 5 изображений.

## Тестирование на собственных изображениях

После обучения модель проверена на отдельной тестовой выборке из 50
изображений: 25 кошек и 25 собак.

Получены следующие результаты:

  Класс                  Precision   Recall     F1-score   Количество
  -------------------- ----------- -------- ------------ ------------
  Cat                       92.31%   96.00%       94.12%           25
  Dog                       95.83%   92.00%       93.88%           25
  **Общая Accuracy**                          **94.00%**       **50**

Матрица ошибок:

  Истинный класс     Предсказан Cat   Предсказан Dog
  ---------------- ---------------- ----------------
  Cat                            24                1
  Dog                             2               23

Модель правильно классифицировала 47 изображений из 50. Количество
ошибок составило 3.

## Выводы

В ходе лабораторной работы реализована система бинарной классификации
изображений кошек и собак на основе свёрточной нейронной сети
MobileNetV3-Small.

Для решения задачи применён Transfer Learning с использованием
предобученных весов ImageNet. Классификатор адаптирован для двух
классов, а обучение проводилось с использованием взвешенной
Cross-Entropy Loss.

На валидационной выборке модель достигла Accuracy **99.32%**. При
проверке на собственной тестовой выборке из 50 изображений точность
составила **94.00%**.

Разница между результатами валидации и независимого тестирования
показывает, что качество классификации зависит от характеристик
изображений: освещения, фона, ракурса, породы и внешнего вида животного.
Несмотря на три ошибки, модель продемонстрировала высокое качество
распознавания обоих классов.

Таким образом, поставленная задача по созданию и тестированию простой
системы классификации изображений на основе CNN выполнена.
